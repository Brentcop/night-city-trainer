# Night City Trainer — notes for contributors and agents

- **Stack:** TypeScript, React 18 and Vite 8, with Vitest 5 for tests and tsx for scripts. No backend. The site is a static build for GitHub Pages (`base: './'`, hash routing).
- **Engine:** `src/engine/engine.ts` (Game class) implements the Comprehensive Rules saved in `data/raw/official_comprehensive_rules.txt`. Card behaviour lives in `src/engine/scripts/<color>.ts`, keyed by card id from `src/data/cards.json`.
  - Scripts use the `CardScript` hooks in `src/engine/types.ts`.
  - State must stay plain data, because bots `structuredClone` it. Never put functions in mods; player `costMod` filters are plain objects (see `costModMatches`).
  - "Next time … this turn" effects from Programs use `g.addDelayed(self, event, data)` together with a `delayed` handler on the script.
  - "First time … each turn" effects read the engine's per-turn history (`g.firstThisTurn(ev.seq, kind, pred)`, `g.turnCount`), not per-card markers.
  - `Game.clone()` drops the log by default; pass `{ keepLog: true }` to keep it (the Play undo snapshot in `src/lib/practiceSession.ts` does).
- **Card data:** `npm run build:data` (`tools/build-data.ts`) regenerates `src/data/cards.json` from `data/raw/sim_catalog.json`.
- **`data/raw/`** (rules text, card catalog, choom.gg pages) is gitignored and local-only: it is not in the repository or the site, so a fresh clone can't run `build:data` or the choom.gg imports.
- **Decks:** `data/decks/*.txt` (meta-*, guide lists) and `data/decks/custom/`. Parse and export them with `src/engine/deck.ts`. Choom.gg imports are refreshed with `scripts/import-meta.ts` and `scripts/import-guides.ts`.
- **Bots:** `src/ai/heuristic.ts` (1-ply lookahead; set `deep: N` for turn rollouts), `src/ai/eval.ts` (tuned weights), `src/ai/knowledge.ts` (roles, ratings, Gig plans). Docs are in `docs/BOT_TOOLKIT.md`.
- **Sims:** `npm run sim -- <catalog|show|vs|test|review|analyze|add>` runs games in worker threads (`scripts/worker.ts`, booted via `worker-boot.mjs`). Other scripts: `scripts/tune.ts` (weight tuning), `scripts/optimize.ts` (card-swap search), `scripts/botcheck.ts` (compare bot configs).
- **Tournaments:** the rules (Swiss, top cut, Bo1/Bo3, seeds) live in `src/lib/tournament.ts`, shared by `npm run tournament -- --field meta --bo 3 --top 8 --bot deep` and the in-browser runner (`#/run`, games run in `src/sim/game.worker.ts` via `src/sim/pool.ts`). Use `makeBot()` (`src/lib/tournament.ts`) for any game that must replay identically: same code + same seed = same game. Bot and engine fixes change results, so events without `simVersion` (`SIM_VERSION`) predate the current code and no longer replay identically. Events live in `public/tournaments/` (index `src/data/tournaments.json`). A game that throws is an error in both the CLI and the browser pool (`src/sim/pool.ts`), never a tie.
- **Run manifests:** every result writer attaches one (`src/lib/runManifest.ts`): `gameRunManifest` for runs that play games (CLI scripts, Matchup Lab, Deck Lab), `aggregateManifest` for files pooled from recorded events (`ratings.ts`, `build-h2h.ts`), which is derived from the input events only so an unchanged rebuild stays byte-identical. Deck ids are `deckFingerprint`s. Keep `schema: 1` readable: add optional fields only, or bump the schema. `rulesVersion`, `faqVersion` and `errataVersion` stay null until they are actually recorded. `npm run check:data` (read-only) checks the event index against the event files, h2h coverage, and manifest deck ids against the stored lists.
- **Card impact** (`src/ai/impact.ts`, Deck Lab) is matched by list fingerprint (`listFingerprint`, carried in games as `PlayerState.listId`), never by deck name alone. The name-only entries in the current `src/data/impact.json` are pinned to their lists in `src/analysis/legacyImpactLists.ts`; delete that table once `npm run sim -- analyze` rewrites impact.json with fingerprints.
- **Play UI:** the practice-session logic (undo, concede, errors, recording) is in `src/lib/practiceSession.ts`, driven by the `usePracticeGame` hook (`src/ui/usePracticeGame.ts`). Concede is a session verdict, not an engine action: it stops the loop like Quit, then records the game once as a conceded loss. Drag-to-act and confirm prompts are in `src/ui/components/board/drag.tsx`. Which cards look actionable comes from `boardMarks()` in `board/interaction.ts`, which reads only the pending decision's options. The log drawer is in `board/LogDrawer.tsx`, and bot speed and the session-long panel flags are in `board/prefs.ts`. `layoutMode()` in `board/layout.ts` (via `useViewport()`) picks the layout. On desktop and tablets the board fills the viewport (`.pb-full` in `board.css`; card sizes come from `--cw` / `--tcg-w`). On phones (`.pb-phone`, portrait or landscape) it is fixed to the screen with sizes from `phoneLayout()`. Phones show prompts in the small right-edge panel in `board/PhoneParts.tsx` (also the ☰ game menu and the card reader). On every layout, prompt cards on the table are picked on the board (`promptChoices()`). The hover preview renders in a portal (`TcgCard`). Undo restores a snapshot (game state plus a cloned bot) taken before each human main-phase decision and continues with `Game.resume()`. Visual replay recording is in `src/lib/replayFrames.ts`.
- **Deck Lab** (`#/lab`, `src/lib/deckLab.ts`) tunes a submitted deck (browser forge) and breeds decks in the browser.
- **Decision telemetry** (`docs/DECISION_TELEMETRY.md`): `g.telemetry = new DecisionRecorder()` (`src/engine/telemetry.ts`) records every decision, observe-only (clones never record); `src/analysis/decisions.ts` reports card use by mode, stage and Gig standing as association, not value. `npm run sim -- analyze --decisions [--out DIR]`.
- **Head-to-heads** (`public/data/h2h.json`, `scripts/build-h2h.ts`) are rebuilt by every tournament run and by `npm run refresh`. The Deck Lab loads them lazily to breed counter decks, and says when they're missing or older than the recorded events.
- **CLIs** print usage with `--help` and exit 2 on unknown flags or invalid values. Data-writing ones refuse to overwrite without `--force`: `npm run tournament` starts after the highest recorded event, `scripts/season.ts` defaults to the next season and won't re-run one, and `sim add` / `import-meta.ts` / `import-guides.ts` / `eor-build.ts` / `theorize-ladder.ts` won't overwrite a deck (they keep provenance headers). `data/reviews/` is gitignored output of `scripts/review.ts`. Unmaintained one-offs live in `scripts/archive/`; don't run them.
- **Before committing:** `npx tsc --noEmit && npx vitest run`. `npm run lint` (react-hooks rules only) and `npm run test:cov` are optional; run `npm run check:data` after changing recorded data. Node 22.12+ (`engines`; `.nvmrc` is `22`).
